# sos-app

Hệ thống cứu hộ khẩn cấp. Dữ liệu lưu trên **Firebase Firestore** (project `sos-app-42d51`), nên mọi máy dùng chung dữ liệu.

- **Người dân**: nhập họ tên + SĐT để vào (không cần đăng ký). Cùng SĐT => thấy lại SOS và tiến trình.
- **Quản trị viên**: bấm "Quản trị" ở góc dưới bên phải màn hình đăng nhập.
- Cần internet để chạy.
